# Product roadmap

| Horizon | Outcome | Evidence gate |
|---|---|---|
| Now | Local governed workflow, 60-case baseline, approval UI | Automated suite + design review |
| Pilot | Authenticated sandbox, durable cases, 5–10 practitioner study | Zero critical failures; measured usability |
| Limited release | RLS database, SSO/RBAC, policy publishing, redacted telemetry, on-call | Privacy/security sign-off + rollback drill |
| Scale | More regions and intents, multilingual evaluation, calibrated LLM drafting | Per-region policy-owner approval + holdout results |

Explicitly out of scope until separately governed: candidate ranking, performance ratings, compensation recommendations, discipline/termination, medical inference, employee monitoring, and autonomous employment actions.
