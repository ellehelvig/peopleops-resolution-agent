# Workflow redesign

| Stage | Current-state pattern | Human + agent future state | Human authority retained |
|---|---|---|---|
| Intake | Email/ticket with missing context | Guided free-text intake and one focused clarification | Employee controls submission |
| Triage | Manual queue reading | Sensitivity-first routing before data access | ER/Legal receive high-risk matters |
| Evidence | Search intranet and multiple systems | Active policy + minimum HRIS fields retrieved through scoped tools | Policy owners govern source truth |
| Interpretation | Variable individual reading | Reproducible rules plus cited draft | People Partner handles exceptions |
| Action | Back-and-forth and unclear ownership | Consequential action pauses in named approval queue | Reviewer approves or rejects |
| Close | Manual reply and weak metadata | Response, source, outcome, and audit event saved together | Case owner resolves |
| Improve | Anecdotes and ticket volume | Failure categories, overrides, latency, adoption, and quality | Governance forum decides changes |
