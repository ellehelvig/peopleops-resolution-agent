# Security policy

This repository is a synthetic portfolio demonstration. Do not enter, commit, upload, or use real employee, applicant, medical, compensation, legal, or authentication data.

## Reporting a concern

Do not open a public issue containing sensitive details. Contact the repository owner privately with the affected component, reproduction steps using synthetic data, and expected versus actual behavior.

## Supported scope

Only the latest `main` branch is maintained. The local demo has no authentication, persistent database, rate limiter, or production secrets system and must not be used as an HR service. See `docs/governance-and-risk.md` for the controls required before any real-data pilot.
