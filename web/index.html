      What this demo is not

      No authentication, no persistent database, no real data. The live demo runs entirely in your browser, so each visitor gets a private session and nothing typed here leaves the page. Authentication, authorization, and data retention are release gates in docs/governance-and-risk.md. The engine is deterministic on purpose so every safety decision can be reproduced; the LLM extension point is documented in docs/architecture.md and must pass the same 60-case contract before it ships.

      Reference implementation. All people, policies, and cases are synthetic. Not legal or HR advice.
